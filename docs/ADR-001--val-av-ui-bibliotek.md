# ADR-1: Val av UI bibliotek

ADR-1: Val av UI bibliotek (shadcn)
Status: Beslutad
Datum: 2026-09-22
Deltagare: Georgij Li, Dmitry Alexandersson, Tomas Savela
Relaterad Issue/Ticket: #22
1. Kontext & Problemställning
Vilken utmaning eller vilket behov står vi inför? Vilka krav och begränsningar styr oss?

Komponentbibliotek används överallt i jobbindustrin så det är bra vänja sig. Vi vill anpassa oss utefter andras externa bibliotek. Vi vill standarisera vårt UI med förbyggda komponenter.

2. Övervägda Alternativ
Alternativ A: Inte använda ett bibliotek. Använda vanlig CSS/tailwind
Fördelar: Enkelt att sätta upp. Det vi använt tidigare.
Nackdelar: Det är inte standariserat. Man återuppvinner hjulet.
Alternativ B: Shadcn bibliotek
Fördelar: Återanvändbara komponenter. Standariserat UI.
Nackdelar: Tar tid att sätta sig in och installera.
3. Beslut
Vilket alternativ valde vi och varför?

Vi valde alternativ B. Vi vill ha ett standariserat UI bibliotek och vi vill öva på att använda det.
