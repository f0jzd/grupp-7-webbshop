# Commit guidelines 
- Prefix commit with: Fix, Refactor, Add, Remove
- Keep commit-message to the point

# Definition of Done
- Has to meet issue Acceptance-criteria
- Check TypeScript logs for warnings
- Clean up unused code, comments and snippets.
- Has been reviewed by someone other than developer
- Has been tested by reviewer
- Works with the rest of the app
- Merged to main
- No known issues remain

If all of the above criteria are meet, update GitHub-issue to Done.
